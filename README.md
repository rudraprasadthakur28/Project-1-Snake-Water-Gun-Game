# Snake Water Gun

My first Python project.

This is a simple Snake, Water, Gun game made using Python.

## How to Play

- Enter `s` for Snake
- Enter `w` for Water
- Enter `g` for Gun

The computer randomly chooses one of the three options.

## Python Concepts Used

- Variables
- Input and Output
- Dictionaries
- Conditional Statements
- `random.choice()`
- `if`, `elif`, and `else`
